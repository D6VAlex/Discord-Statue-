## About

**Discord Status** is a simple Python project designed to customize your Discord activity using Rich Presence.

You can configure your application details, upload custom artwork, and display your preferred activity information directly on your Discord profile.

## Features

Custom Discord Application ID.
Custom Rich Presence artwork.
Large Image Key support.
Custom activity details and state.
Simple graphical interface.
Easy configuration.

## Getting Started

### 1. Create a Discord Application

Visit the [Discord Developer Portal](https://discord.com/developers/applications).

1. Create a new application.
2. Open **General Information**.
3. Copy your **Application ID**.

<img src="https://github.com/user-attachments/assets/bacc6214-4740-4380-b177-dfaf90b359b0" width="500" alt="Application ID">

Paste the Application ID into the application.

### 2. Upload Your Custom Image

Go back to your Discord Developer Portal.

1. Open your application.
2. Navigate to **Rich Presence**.
3. Open **Art Assets**.
4. Click **Add Image(s)**.
5. Upload your image.

**Recommended image specifications:**

| Property | Requirement |
|---|---|
| Formats | PNG, JPG, JPEG |
| Recommended | 1024 × 1024 |
| Minimum | 512 × 512 |

<img src="https://github.com/user-attachments/assets/075c9bb1-b1b2-44d1-baf1-5f5252b3bca3" width="400" alt="Discord Art Assets">

### 3. Copy Your Image Key

After uploading your image, copy its asset name (Image Key).

<img src="https://github.com/user-attachments/assets/a54b115d-51ec-4f4e-b28f-8ee0c8f593c6" width="750" alt="Upload Image">

### 4. Configure Your Application

Paste the copied Image Key into the **Large Image Key** field in Discord Status.

<img src="https://github.com/user-attachments/assets/4b6700f1-a6f4-4117-8123-d677f68dfba2" width="450" alt="Large Image Key">

### 5. Start Your Rich Presence

Make sure Discord is running, complete your configuration, and press **Start**.

Your customized activity should now appear on your Discord profile.

## Troubleshooting

**Image not showing?**
Make sure the Image Key matches the uploaded asset name.
Check that the image has finished uploading.
Verify that you are using the correct Application ID.

**Rich Presence not appearing?**
Make sure Discord Desktop is running.
Restart the application.
Verify your Discord Application configuration.
